# Проверка набора MazeHell

- 47 PNG сверены с `inventory.json`: размеры, наличие файлов и настроек импорта.
- 42 спрайта имеют прозрачные и непрозрачные пиксели. Палитровые PNG проверены с учётом PNG transparency.
- У всех четырёх тайлов противоположные RGB-границы совпадают точно.
- Шесть GIF содержат по четыре кадра.
- Повторный импорт FBX в Blender: шесть mesh-объектов, анимационные дорожки присутствуют.
- Шрифт: `fc-query` подтвердил Press Start 2P и диапазон кириллицы U+0400–U+045F.
- Визуально проверены все позы беса, 24 кадра лица, иконки, тайлы, меню, рендер кристалла. Исправленные кадры оружия отдельно проверены на два ствола и два патронника.
- Проверка в запущенной сцене Unity не выполнялась; набор поставлен как графические ресурсы.

## Самопроверка

| Критерий | Оценка | Основание |
| --- | --- | --- |
| Точность | 4/5 | Файлы и геометрия на спрайтах проверены; визуальная оценка внутри игрового HUD Unity остаётся следующим этапом интеграции. |
| Полнота | 5/5 | Все исходные категории, расширение до 24 кадров лица, кириллический шрифт и модель кристалла включены. |
| Ясность | 4/5 | README и JSON описывают назначение кадров; обзорные листы оружия не подписаны, порядок указан в именах файлов. |
| Практичность | 4/5 | PNG готовы к импорту, есть тайминги и FBX; URP Emission для FBX назначается при подключении модели, исходные emissive-материалы доступны в Blender/GLB. |
| Краткость | 4/5 | Основная инструкция собрана в одном README; технические исходники отделены от игровых PNG. |

Среднее: 4.2/5. Наибольшая польза при следующем этапе: проверить масштаб портрета и ружья в реальном HUD, затем назначить URP-материалы кристаллу. Оценка отражает готовность ресурсов; пользовательскую оценку художественного результата она не заменяет.
