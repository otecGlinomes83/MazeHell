# MAZEHELL — ГДД (Game Design Document)

Версия: 0.1 · 2026-10-16 · Статус: согласовано на концепте, числа = стартовые, всё тюнится

---

## 1. Обзор

> Быстрый ретро-шутер в духе классического Doom: бесконечные процедурные лабиринты ада.
> Зачисти уровень, войди во тьму, иди глубже. Умри — начни заново.

- **Жанр:** бесконечный ретро-FPS («бумер-шутер») с процедурной генерацией
- **Платформа:** Яндекс Игры (WebGL). Этап 1 — десктоп, этап 2 — мобилки (тач)
- **Камера:** от первого лица, у игрока видны только руки с двустволкой
- **Референсы:** Doom / Doom II (ритм, враги, гибы), Dusk (скорость), Hrot (мрачность)
- **Подписи игры:** ритуал перехода во тьму; двустволка с залпом; блок-отбив; распрыжка с бхопом; дум-фейс в ХУДе
- **Сессия:** забег бесконечен до смерти; цель уровня 60–120 секунд реального времени

## 2. Основной цикл

```
Спавн в лабиринте
   → ищи и убивай всех врагов (дверь закрыта, пока жив хоть один)
   → последний убит: рог + дверь светится
   → дверь вела в тёмный коридор: 10–15 сек ходьбы во тьму (подгрузка нового уровня)
   → УРОВЕНЬ N+1: лабиринт больше, врагов больше, враги злее
   → … пока не умрёшь
```

Смерть = конец забега → экран результата → «ЕЩЁ РАЗ» одной кнопкой. Прогресса между забегами нет — растёт только игрок.

## 3. Игрок

### 3.1 Здоровье и лечение

| Параметр | Значение |
|---|---|
| Макс. ХП | 100 |
| Лечение за убийство | по типу врага: Бес +10 (будущий танк +25 и т.д.) |
| Оверхил | нет |
| Индикация урона | дум-фейс (скалится, кровоточит) + учащённое сердцебиение + лёгкая виньетка |

Убивай — лечись: агрессия — это защита. Пассивной регенерации нет.

### 3.2 Движение и распрыжка

Игрок всегда быстр, спринта нет — это база дум-вайба.

| Параметр | Значение (стартовое) |
|---|---|
| Скорость по земле | ~7 м/с |
| Прыжок | есть, невысокий (~1 м) — инструмент, а не вертикальность |
| Бхоп (распрыжка) | прыжок в короткое окно после приземления (~0.15 с) сохраняет скорость без трения; разгон стрейфами в воздухе по соурс-модели |
| Потолок скорости | мягкий кап ~12 м/с (~1.7× базы), выше — затухание |
| Урон от падения | нет |

Бхоп — заявка на скилловое движение: идеально отыгранный забег выглядит как полёт по коридорам. Следствие для генерации: коридоры и залы проектируются так, чтобы были прямые полосы для разгона.

### 3.3 Рывок

| Параметр | Значение |
|---|---|
| Кнопка | Shift (по умолчанию; Space занят прыжком) |
| Длительность | ~0.18 с, ×3 скорости, в направлении движения |
| Неуязвимость | да, ~0.2 с — можно проскочить сквозь выпад |
| Кулдаун | ~1.5 с, индикатор-пип у прицела |

### 3.4 Блок (отбив стволами)

Двустволка поперёк — стойка блока.

| Параметр | Значение |
|---|---|
| Кнопка | ПКМ (удержание) |
| В стойке | скорость ×0.6, стрелять нельзя |
| Успешный блок (поймал удар в стойке) | урон ×0.3, игрока отталкивает ~1.5 м, враг в шоке ~0.6 с, тряска + звук отбива |
| Кулдаун блока | ~2 с **после успешного срабатывания** |
| Блок на кулдауне | стойку держать можно, но урон не режет — честно наказывает за спам |

Идея петли: не успел уйти рывком — блокуй; застаканил врага — накажи залпом в упор.

### 3.5 Управление (десктоп, этап 1)

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь | обзор, pointer lock |
| ЛКМ | выстрел (быстрый повторный клик = залп) |
| ПКМ (удержание) | блок |
| Space | прыжок / распрыжка |
| Shift | рывок |
| Esc | пауза |

## 4. Оружие: двустволка

Единственное оружие. Патроны бесконечны — суть в динамике, а не в экономике.

| Параметр | Значение |
|---|---|
| Заряды | 2 ствола, стреляют по очереди |
| Выстрел | ЛКМ — один ствол; минимальный интервал кликов ~0.12 с |
| Залп («жёсткий выстрел») | второй клик в окне ~0.25 с — оба ствола мгновенно: двойной дроби, отбрасывание врагов, сильная тряска, вспышка |
| Урон | 8 дробин × 2.5 ≈ 20 вблизи; залп ≈ 40 — Бес (30 ХП) умирает с залпа в упор |
| Перезарядка | оба ствола пусты → пауза ~0.6 с, анимация перелома; стрелять нельзя |
| Окно залпа | ~0.25 с между кликами |

Вьюмодель как в оригинале Doom: оружие — **UI-спрайт** внизу по центру экрана (кадры: спокойствие, выстрел ствола, залп, перезарядка-перелом). 3D-руки не рендерим вообще. Покачивание спрайта при ходьбе, вспышка выстрела на миг освещает коридор.

Дизайн-ритм: тук-ТУК (два одиночных) или БУХ (залп) — выбор между экономией выстрелов и мгновенным уроном. Залп в толпу = отбрасывание = передышка.

## 5. Враги

### 5.1 Бес — монстр №1 (MVP, единственный тип)

Быстрый ближник-демон. Держит игрока в постоянном движении.

| Параметр | Значение (стартовое) |
|---|---|
| ХП | 30 |
| Скорость | ~6.2 м/с — чуть медленнее бегущего игрока |
| Урон удара | 15–18 |
| КД атаки | ~0.8–1.0 с |
| Лечение игроку за убийство | +10 |

**Поведение (конус интеллекта, без перегруза):**

```
ЗОНА (спит/тушуется в своей зоне лабиринта)
   → услышал выстрел (радиус слуха ~25 м, сквозь стены)
        → ИДЁТ ПРОВЕРЯТЬ точку шума
             → никого нет → ВОЗВРАТ в зону
   → увидел игрока (конус зрения только перед собой, ~90°, дальность ~12 м,
     сквозь стены НЕ видит)
        → ПОГОНЯ (не отстаёт, бежит напрямую, огибая стены)
             → подошёл на ~2.5 м → ЗАМАХ 0.35–0.4 с (телеграф: вскидывается, шипит)
                  → ВЫПАД-прыжок 3–4 м
                       → попал: урон + лёгкий отброс игрока
             → КД атаки ~1 с → снова замах
   → потерял игрока из виду надолго → ищет у последней точки → проверка → возврат
```

- Телеграф замаха читается и глазами (анимация), и ушами (шипение) — дуэль: прочитай, уйди рывком/бхопом или поймай блоком, накажи.
- Флинч от попаданий есть, но замах на последних ~0.15 с не прерывается — враг не станлочится насмерть.
- Враг — **спрайт на примитиве**: квад-биллборд, всегда повёрнут к камере. Никакого 3D-меша у монстра.
- Попадания читаются сменой кадра: короткий «уронный» кадр при флинче. Без гибов и 3D-кусков.
- Смерть: спрайт меняется на трупный кадр, труп остаётся лежать плоским спрайтом. Декали крови — опционально, в MVP можно без них.
- Задел на будущее (не MVP): танк (медленный, жирный, хил +25), стрелок снарядами, стая слабых — архитектура врагов закладывается под несколько типов сразу, но в MVP тип один.

## 6. Уровень: лабиринт и генерация (дизайн-требования)

- **Структура:** классический лабиринт из коридоров, которые местами расширяются в **залы** с колоннами — залы = основные арены, где толпу интересно вести.
- Ширина проездов рассчитана под распрыжку: где-то всегда должна быть прямая полоса для разгона.
- **Вход и выход:** спавн и врата-выход — максимально далеко друг от друга (по графу лабиринта).
- Враги раскиданы по своим зонам; часть — в залах.
- **Дверь закрыта**, пока жив хоть один враг. После последнего убийства: низкий рог, дверь начинает светиться/дымиться.
- **Переход:** за вратами — тёмный коридор. 10–15 секунд ходьбы: свет гаснет, музыка утихает, шаги и сердцебиение. В это время следующий уровень генерируется. Затем затемнение → сплэш «УРОВЕНЬ N».
- Тема: **ад** — тёмно-красный камень, трещины лавы и жаровни как источники света, кости, густой тёмный туман.
- **Пикапы:** летающий хил-орб (3D-модель из Blender, единственная «живая» 3D на уровне помимо стен), +25 ХП при подборе [число тюнится]. Позже возможен бафф к урону.

## 7. Прогрессия и сложность

Каждый уровень давит всем сразу — игрок растёт только скиллом, апгрейдов нет.

| Параметр | Старт (ур. 1) | Рост | Кап |
|---|---|---|---|
| Врагов на уровне | 8 | +3 за уровень | ~40 |
| Сторона лабиринта (клетки) | 16 | +2 за уровень | ~36 |
| Скорость врага | 6.2 м/с | +1.5% за уровень | +25% |
| ХП врага | 30 | +2 за уровень | 50 |

Точные точки капа — после плейтестов; кап нужен, чтобы на 15-м уровне не начался абсурд.

## 8. Смерть, счёт, мета

- Смерть = конец забега. Экран: **уровень, убийства, время**, личный рекорд.
- **Лидерборд Яндекса:** достигнутый уровень (тай-брейк — убийства).
- Забег всегда с 1-го уровня, сохранений середины нет.
- Экран смерти: «ТЫ УМЕР» + статы → **[ЕЩЁ РАЗ]** (мгновенный рестарт) и [В МЕНЮ].
- Главное меню: MAZEHELL, [НАЧАТЬ], рекорд, лидерборд, язык, звук.
- Локализация: **русский + английский** с переключателем, все строки через таблицу строк с первого дня.

## 9. UI / HUD

Минимализм, ретро-шрифты, ничего лишнего на экране:

- **Прицел** + 2 пипа стволов (пустой/заряжен) + пип рывка.
- **Дум-фейс** — портрет игрока в углу: состояния от ухмылки до окровавленной маски + реакция на полученный удар (запекается из 3D, как враги).
- Полоса/число ХП, счётчик врагов (череп + число), номер уровня сплэшем на старте.
- Пауза (Esc): продолжить, заново, звук, чувствительность мыши.

## 10. Звук

Музыка: **мрачный агрессивный индустриал/метал луп**, давит весь забег.

SFX (звук — половина дум-вайба, каждый игровой сигнал дублируется ухом):

- Двустволка: слоёный жирный выстрел; лязг перелома при перезарядке
- Бес: рык в покое, лай при обнаружении, **шипение замаха** (телеграф), визг выпада, боль, хлюп смерти
- Шаги игрока и врагов; сердцебиение (учащается при низком ХП и в тёмном коридоре)
- Рог при открытии двери; гул врат; UI-клики
- Важно для WebGL: звук стартует только после первого клика игрока

## 11. Визуальный стиль

- **Враги:** спрайты на примитивах — квад-биллборды с покадровыми спрайтами (запекаем из 3D в Blender или рисуем). Открытый вопрос: биллборд «всегда лицом» или 8 направлений.
- **Мир:** стены и геометрия уровня — 3D из Blender, low-res текстуры 64–128 px с nearest-фильтрацией, простой свет, тёмный туман. Пиксельность — фича.
- **Оружие:** UI-спрайт поверх экрана, как в оригинальном Doom. 3D-рук у игрока нет.
- **Единственный «живой» 3D:** стены/геометрия из Blender + летающий хил-пикап (+ будущие баффы).
- **Кровь/гибы:** в MVP их нет — урон и смерть читаются сменой кадров спрайта врага.

## 12. Технические рамки (только рамки, без архитектуры)

- Unity 6000.4, **Built-in Render Pipeline** (мигрировали с URP), билд **WebGL → Яндекс Игры**
- Игрок — **CharacterController + собственная модель скорости** (трение на земле, air-accelerate, бхоп, дэш и отбросы пишутся прямо в вектор скорости); Rigidbody на игроке не используем, физика — только второстепенным объектам
- Цели производительности: 60 FPS на среднем железе, вес билда ≤ 40 МБ, загрузка ≤ 10 с
- Этап 1 — десктоп (мышь+клавиатура); этап 2 — мобилки (тач: левый стик — движение, правый — обзор, кнопки огня/рывка/блока, вероятно автодоводка прицела)
- Тач-вариант — после играбельной десктопной версии

## 13. Открытые вопросы

1. **Идеальный блок** (предложение, не подтверждено): блок, поднятый <0.25 с до удара, — урон 0, стан врага 1 с, сброс КД рывка. Проверить на плейтесте — не перегиб ли.
2. **Спрайты врагов:** биллборд «всегда лицом» (дешевле, почти вдвое меньше кадров) vs 8 направлений (думовее). Решить по первым запечённым кадрам.
3. **Кап бхопа** ~12 м/с — проверить, не ломает ли баланс лабиринта и выпадов.
4. Точные числа всей таблицы баланса — после первого плейтеста.
