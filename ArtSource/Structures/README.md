# MAZEHELL — статические структуры

Актуальная версия после правок пользователя: увеличенные залы, сплошные тёмные деревянные двери, тёмно-красные каменные колонны и обрамления врат. Предыдущие концепты в `Concepts/` — архив первого прохода, не текущие чертежи.

Рендер: URP Forward. Graphics и все уровни Quality используют Assets/MazeHell/Settings/MazeHell_Web_RPAsset.asset. Материалы URP/Lit; чёрный переход URP/Unlit. SSAO: половинное разрешение, 4 сэмпла; Neutral tonemapping и лёгкая цветокоррекция. Предыдущие настройки сохранены в RenderPipelineBackup/.

## Границы работы

Это только геометрия, материалы, отдельные двери и статическая демонстрационная карта Unity. **Автооткрывание дверей, граф/связи узлов, триггеры переходов, полёт камеры, динамический бюджет света и редакторский генератор удалены вместе с C#-файлами.** Скрипты общей настройки света — `Assets/MazeHell/Scripts/Level/StructureLightingController.cs` и `StructureLight.cs`. Декора нет.

Для осмотра использовать штатный Scene View Unity. Камера Game — неподвижная, без контроллера. Все двери закрыты в исходном положении. Цельное полотно перемещается вертикально общим корневым Transform: Unity Y, Blender Z. Анимация не добавлена.

| MH_Column_Stone | тот же красный камень Hellstone, затемнённый; колонны и обрамление больших врат |
| MH_Column_Band | ещё более тёмный красный камень баз/капителей |

Колонны каменные, не деревянные, без светлого контрастного материала. Обрамление врат также из более тёмного красного камня. Вход/выход выделяются шириной, высотой и ступенчатым силуэтом, а не отдельной игровой логикой. Обычные двери прямоугольные. Двери имеют одно цельное полотно с общим пивотом внизу по центру для вертикального движения; боковых створок, петель и компонентов поведения нет.

## Свет

На корневом объекте `MAZEHELL / Static architecture` — Structure Lighting Controller. Группы Rooms, Corridors одновременно меняют цвет, интенсивность, радиус и тени через OnValidate. Маркер StructureLight задаёт группу. Включённость источников ручная; никаких автоматических переключений по камере. Свет белый; интенсивности адаптированы для URP: Rooms 45, Corridors 18. Gate Light удалён. Структурные префабы сами по себе не содержат источников света или декора.

## Рельеф и матовость

Пять общих normal maps в Assets/MazeHell/Resources/Textures/Normals/ используются восемью текстурированными материалами (камень, кости, лава, пол/потолок, колонны, дерево). Это приближённый рельеф из яркости исходных текстур, рассчитанный импортёром Unity (Normal map / Create from Grayscale, Bumpiness 0.08), не запечённые high-poly нормали. Камень Smoothness 0.08, дерево 0.12, металл 0.22. Нормали не меняют силуэт или коллизии.

Свет: штатный URP Low tier 128 px на каждую грань point shadow, общий атлас 2048, дальность теней 35 м. Gate Light отсутствует. Общая настройка комнат и коридоров — прежний StructureLightingController.

Обоснование WebGL и текущая проверка сборки: WEBGL_RENDERING.md.
